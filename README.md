# N40

Замена K40 Whisperer для CO₂-лазеров K40 с контроллером **M2 Nano / Lihuiyu (LHYMICRO-GL)**.
Русский интерфейс, камера над полем, нестинг, примитивы и булевы операции.

## Возможности

- **Импорт** нескольких файлов сразу (диалог и drag-and-drop): SVG (DPI 96/90/72, viewBox, ручной масштаб),
  DXF (единицы из `$INSUNITS`), PNG/JPG/BMP/GIF/TIFF, PDF/AI (вектором через Inkscape, иначе растром).
- **Рабочее поле** в мм, начало координат — левый верхний угол (как у K40), сетка 1/5/10 мм, линейки,
  координаты курсора, масштаб колесом, панорамирование средней кнопкой, привязка к сетке и узлам.
- **Примитивы**: прямоугольник (в т.ч. скруглённый), окружность, эллипс, линия, многоугольник,
  правильный N-угольник, текст системными шрифтами → кривые. Shift — квадрат/круг/угол 45°.
- **Операции**: перемещение, поворот, отражение, масштаб, выравнивание, распределение, группировка,
  объединение/вычитание/пересечение, линейный и круговой массив, эквидистанта (pyclipper), отмена/повтор.
- **Нестинг**: размер листа, зазор, отступ, углы (0/90/180/270 или шаг), число копий, детали в отверстиях,
  коэффициент использования K = ΣS_деталей / S_листа × 100 %, фоновый расчёт с кнопкой «Остановить».
  **Раскрой по фото** — обведите на подложке камеры свободный обрезок («Область раскроя») и/или
  «Запретные зоны».
- **Камера** (USB UVC или RTSP/HTTP-FLV/MJPEG): живая подложка, мастер калибровки —
  дисторсия по шахматной доске и перспектива по 4 точкам (метки можно выжечь лазером).
- **Лазер**: резка / гравировка контура / растр (дизеринг или порог), скорость и проходы на объект,
  внутренние контуры режутся первыми, «Рамка», пауза/стоп, перемещение, экспорт `.EGV`.
- **Обновления** через GitHub Releases.

## Запуск из исходников

```
python -m pip install -r requirements.txt
python run_n40.py
```

Драйвер USB: как для K40 Whisperer — через [Zadig](https://zadig.akeo.ie/) установите **WinUSB**
(или libusb-win32) для устройства `USB-EPP/I2C... CH341A` (VID 1A86, PID 5512).
`libusb-1.0.dll` поставляется пакетом `libusb-package`.

## Сборка .exe и установщика

```
powershell -File packaging\build.ps1
```

Нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php). Результат: `dist\N40.exe` и `dist\N40-Setup-<версия>.exe`.

## Выпуск обновления

1. Поднять `__version__` в `n40/__init__.py`.
2. `git tag v0.1.1 && git push --tags` — GitHub Actions соберёт установщик и опубликует релиз.
3. Установленные копии N40 при запуске предложат обновиться.

## Структура

```
n40/core/      ядро без GUI: геометрия, примитивы, импорт, нестинг, планировщик, камера, обновления
n40/core/driver/  LHYMICRO-GL (кодировщик) и USB-транспорт
n40/gui/       PySide6: рабочая область, панели, диалоги, мастер калибровки, фоновые потоки
packaging/     PyInstaller, Inno Setup, скрипт сборки
```

## Важно

- Протокол LHYMICRO-GL не документирован; реализация написана заново по описанию из
  [MeerK40t](https://github.com/meerk40t/meerk40t) (MIT) и [K40 Whisperer](https://www.scorchworks.com/K40whisperer/k40whisperer.html) (GPL-3.0).
  Перед первым запуском сравните экспорт `.EGV` с K40 Whisperer и проверьте задание на малой мощности.
- Мощность лазера у K40 задаётся ручкой/кнопками на панели станка, программно — только скорость.
- Windows 7 стеком Python 3.11+ / Qt 6 не поддерживается (минимум Windows 10).
